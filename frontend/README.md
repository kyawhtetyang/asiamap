# AsiaMap Frontend

Next.js App Router frontend for the AsiaMap transportation website.

## Pages
- `/`
- `/services`

## Local Run
```bash
cd /Users/kyawhtet/Documents/EDU/execution/02_Web/10_AsiaMap/v0/frontend
npm install
npm run dev
open http://127.0.0.1:3000/
```

## Build
```bash
npm run build
```
